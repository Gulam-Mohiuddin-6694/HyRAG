# HyRAG: Hallucination-Aware Hybrid Retrieval System

An enterprise-grade, Multi-Document Question Answering system featuring hybrid retrieval and hallucination verification.

## 📌 Features (Planned)
- Multi-document parsing and indexing
- Hybrid Retrieval (Dense Vector + Sparse Keyword Search)
- Hallucination detection & citation verification
- Modular support for Free LLMs (Google Gemini API / Groq API / Local models)

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Framework:** FastAPI / LangChain / LlamaIndex
- **Vector Store:** FAISS / ChromaDB
